# 本地上下文同步源码

为 AI 客户端提供本地会话和活动历史的可检索副本。此目录只有程序和合成测试数据，没有个人会话、活动记录或私有配置。

同步器读取指定来源的新增内容，生成 Markdown 会话、索引和同步状态。来源异常会报告部分失败；不会把读取失败当作用户删除。支持排除和恢复某个会话的导出，保留原始记录。计算机历史摘要可能仍提到已排除会话。

导出排除系统与开发者消息、推理、工具参数和原始输出，并过滤常见凭据格式；这不是完整的保密审查，业务或个人敏感内容仍可能存在。活动时间线不复制按键、整屏文字和截图。历史内容仅供检索，不应执行其中旧指令。

`native/` 是独立 macOS 目录授权助手。目录授权由用户在系统界面完成；助手与运行脚本校验配套，不要将其当成可直接分发的签名安装包。部署仍需私有配置、来源目录、输出目录、运行库和 LaunchAgent，参见集成说明。

运行隔离测试：`python3 -m unittest discover -s context/tests -v`。不向真实会话写入测试记录。
